# 小蛙回家路

一个面向微信/抖音小游戏方向的竖屏无尽玩法原型。核心操作严格保持为：

> 按住屏幕蓄力，松开后自动朝下一片荷叶跳跃。

## 运行

```bash
npm start
```

浏览器打开 `http://127.0.0.1:4173`。电脑使用鼠标，手机使用触摸操作。

## 测试

```bash
npm test
```

## Cocos Creator 工程

早期迁移版位于 [`cocos-project`](./cocos-project)，使用 Cocos Creator 3.8.8。目前以 H5 版本作为正式开发基线，Cocos 工程只保留作对照和备份。

Cocos 旧版构建方式见 [`cocos-project/README.md`](./cocos-project/README.md)。

## 当前原型包含

- 单指按住/松开操作
- 自动朝向下一落点
- 基于蓄力时间的抛物线跳跃
- 荷叶落点与边缘容错判定
- 可复现的无限荷叶生成和镜头持续推进
- 五档渐进难度、逐段收紧的落点容错、每十步休息荷叶和难度恢复波次
- 每十步一轮的短跳、长跳、缓冲和压轴节奏
- 前二十步逐渐淡出的蓄力落点提示、四脚伸展、荷叶下沉、险落晃动与震动反馈
- 每十五步切换晨雾、晴光、晚霞和月夜荷塘氛围
- 精准落地连击与本地最高纪录
- 萤火虫永久积累和本局收集反馈
- 每局轮换目标、每十步阶段奖励和明确的奖励进度
- 落水后提示力度偏小或偏大，低步数失败优先立即重开
- 每局一次蜻蜓救援（模拟激励广告）和无尽模式结算
- 可供微信/抖音适配层接管的基础行为统计事件
- 开始页、结算页、轻量音效与程序绘制美术
