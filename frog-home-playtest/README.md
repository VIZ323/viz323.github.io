# 小蛙回家路

一个面向微信/抖音小游戏方向的竖屏玩法原型。核心操作严格保持为：

> 按住屏幕蓄力，松开后自动朝下一片荷叶跳跃。

## 运行

```bash
npm start
```

浏览器打开 `http://127.0.0.1:4173`。电脑使用鼠标，手机使用触摸操作。

## 测试

```bash
npm test
```

## 当前原型包含

- 单指按住/松开操作
- 自动朝向下一落点
- 基于蓄力时间的抛物线跳跃
- 荷叶落点与边缘容错判定
- 镜头跟随和连续关卡推进
- 萤火虫完美落点评分
- 落水、蜻蜓救援（模拟激励广告）和重新开始
- 开始页、通关页、轻量音效与程序绘制美术
